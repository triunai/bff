# Source and evidence boundary

BFF bootstrap code and portable operating instructions are authored for this distribution. Prior personal workflows informed the design; private source repositories, application rules, customer data, machine paths, vault notes and historical records are excluded.

The runtime aeh prototype is a separate candidate integration and is not vendored. OMC, OMX, Herdr, Beads, Gas and DSH are not bundled. Since v0.1.1, `bff doctor` can install or upgrade the ones with a verified package-manager route (Homebrew or npm), and only after the user confirms the printed plan or passes `--yes`; BB and aeh stay manual. Their availability does not establish a connected adapter.

The optional Osiris observer uses BB's public plugin SDK. BB itself and its SDK dependencies are separate upstream products and retain their own licenses. Prebuilt assets and any required bundled dependency notices are reviewed separately before inclusion. See component attribution when a plugin is bundled.

This release contains a declared subset of spine checks, not the entire written operating model as enforcement. Local tests are local evidence; no remote branch-protection or production-readiness claim follows from a release asset.
