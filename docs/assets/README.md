# README assets

Images referenced by the top-level [README](../../README.md). They are captured by hand; none are generated. Dark theme, real data from your own sessions (check for secrets, paths and tokens before committing), about 1600 px wide, PNG unless stated.

| File | View and state to capture | Where it is used |
| --- | --- | --- |
| `osiris-workbench.png` | Main Osiris view in BB with a real thread open: Work list on the left, native chat in the centre, Changes on the right showing a non-empty diff. Whole window, no overlays. | Hero image under the pitch |
| `osiris-toolcalls.png` | The separate **Toolcalls** sidebar entry with search set to `status:error`, results visible, coverage and source indicators showing. | Osiris section |
| `osiris-failed-call.png` | A selected failed call in the inspector, with its metadata panel open. Capture it as it is; do not stage fields that the collector leaves as Unknown. | Osiris section |
| `osiris-demo.gif` | 10 to 20 seconds, at most about 1200 px wide and 5 MB: open Toolcalls, type `status:error`, select a failed call. No narration, no cursor jitter. | Osiris section |
