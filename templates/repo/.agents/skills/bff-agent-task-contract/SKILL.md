# Agent task contract

Inspect the target repo's hygiene.md and relevant rules before dispatch. Verify the brief's factual premises against current source; a dated claim or zero-match search is not proof.

Every packet states ten things: mission; source context; ownership; input/output contracts; allowed scope; non-goals; phase/dependency plan; validation gates; evidence destination; handoff/resume and unverified items. Each must be concrete or explicitly inapplicable. Gate commands come from the repo's bindings, not a universal npm/SQL list.

Choose topology by dependency shape: shared primitives first, independent consumers in isolated worktrees after the contract settles. One writer per worktree, one owner for shared configuration. Use an explicit model; keep the day's staffing roster out of durable conventions.

Require inspect → execute → validate, with deviations reported. Name the intended base and check merge-base ancestry at dispatch and integration. Lanes commit passing steps and write only their assigned code/evidence. The orchestrator retains spine ownership and numbering.

Handoff must identify commits, actual checks/test execution, contract deviations, risks and what could not be verified. Builder receipts need independent verification before LAND. Resolve verb order through hygiene.md; this skill does not own it.
