# Evidence router

Lanes place immutable dated audit/review/check evidence here using names assigned in their task contracts. The orchestrator indexes it. Every record identifies source/base, scope, actual commands/results, author/verifier and what could not be verified. Keep raw secrets/prompts and private environment files out.

Landing records map each promise to proof and an independent verifier. Agent done messages, review launch attempts and green wrappers are claims, not landing evidence. Correct an old record with a new artifact, never a historical rewrite.
